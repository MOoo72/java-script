## 📖 About This Repository

This repository documents my ongoing journey of learning and practicing **JavaScript**. It brings together practical coding questions and short theoretical explanations to reinforce fundamental programming concepts, improve problem-solving skills, and develop a stronger foundation for future projects.

Rather than focusing on a single application, this repository serves as a growing **practice notebook** where I can experiment, revise, and track my progress.

## 🧠 Topics Covered

The current exercises and notes explore:

- **Variables and data types** — values, comparisons, truthy/falsy checks, and type conversion.
- **Control flow** — `if` statements, `switch`, loops, and `continue`.
- **Arrays and strings** — `map()`, `filter()`, `split()`, and the spread operator.
- **Functions** — function declarations, arrow functions, parameters, and rest parameters.
- **Objects** — destructuring and `Object.keys()`.
- **Asynchronous JavaScript** — introductory promises and `setTimeout()`.
- **Core concepts** — hoisting, the temporal dead zone (TDZ), equality operators, and error handling.

## ▶️ Getting Started

You'll need **Node.js** installed to run the exercises locally.

1. Clone the repository:

   ```bash
   git clone https://github.com/MOoo72/java-script.git
   ```

2. Open the project directory:

   ```bash
   cd java-script
   ```

3. Run the practice file:

   ```bash
   node course.js
   ```

> **Note:** The file contains multiple independent exercises. Some examples are intentionally written for practice and may require further refinement. Review or run individual sections when studying a specific topic.
